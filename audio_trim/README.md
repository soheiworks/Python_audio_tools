# Audio Trim Tool

M4A形式の音声ファイルの冒頭部分を、指定した秒数だけカットするツールです。

## 使用ファイル

- `trim_m4a_start.py`：音声カット処理を行うPythonスクリプト
- `run_trim_m4a_simple.bat`：起動用バッチファイル（Windows用）

## 必要な環境

- Python
- FFmpeg

FFmpegはインストール後、コマンドラインから `ffmpeg` を実行できるようにPATHを設定してください。

## 使い方

### 1. バッチファイルから実行する（Windows）

1. 2つのファイルを同じフォルダに配置します。
2. `run_trim_m4a_simple.bat` を実行します。
3. カットする秒数を入力します。

### 2. Pythonから直接実行する

スクリプトとM4Aファイルを同じフォルダに配置し、コマンドラインから実行します。

```bash
python trim_m4a_start.py 5
```

冒頭5秒をカットします。

再エンコードして、より正確な位置でカットする場合：

```bash
python trim_m4a_start.py 3.5 --reencode
```

元ファイルを上書きせず、`trimmed` フォルダに出力する場合：

```bash
python trim_m4a_start.py 5 --outdir trimmed
```

## 動作について

- 対象はスクリプトと同じフォルダにあるM4Aファイルです。
- デフォルトでは再エンコードせず、高速に処理します。
- 再エンコードしない場合、カット位置が指定秒数から数十ミリ秒程度ずれることがあります。
- `--reencode` を指定すると、再エンコードによってカット位置の精度が向上します。

## 注意事項

**通常の実行では、元の音声ファイルが上書きされます。**

必要に応じて、事前にバックアップを取ってください。

元ファイルを残したい場合は、`--outdir` オプションを使用してください。
