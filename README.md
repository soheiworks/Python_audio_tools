# Python Audio Tools

音声ファイルを処理するための個人制作ツールです。

現在、以下の2つのツールを収録しています。

## 1. Audio Trim

M4A形式の音声ファイルの冒頭部分を指定した秒数だけカットするツールです。

### 使用ファイル
- `trim_m4a_start.py`：音声カット処理
- `run_trim_m4a_simple.bat`：起動用バッチファイル

### 必要な環境
- Python
- FFmpeg

### 使い方
1. 2つのファイルを同じフォルダに配置します。
2. `run_trim_m4a_simple.bat` を実行します。
3. カットする秒数を入力します。

**注意：** 通常の起動方法では、元の音声ファイルが上書きされます。必要に応じて事前にバックアップしてください。

Pythonから直接実行する場合は、出力先フォルダを指定することもできます。

## 2. Audio Speed Converter

M4A形式の音声ファイルを2.25倍速に変換するツールです。

### 使用ファイル
- `Convert_m4a_speed.ps1`：音声変換処理
- `Convert_m4a_speed.bat`：起動用バッチファイル

### 必要な環境
- Windows
- PowerShell
- FFmpeg

### 使い方
1. 2つのファイルを同じフォルダに配置します。
2. 変換したいM4Aファイルを同じフォルダに入れます。
3. `Convert_m4a_speed.bat` を実行します。

変換後のファイルは `x2.25` フォルダに保存されます。

変換に成功した元ファイルは `済` フォルダに移動されます。

**注意：** 同名ファイルが「済」フォルダに存在する場合、上書きされる可能性があります。必要に応じて事前にバックアップしてください。
